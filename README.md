# 🛰️ Space Traffic Control AI

## Overview

Space Traffic Control AI is a project that analyzes satellite traffic and orbital congestion using data visualization and AI concepts.

As the number of satellites in orbit continues to increase, monitoring traffic and identifying crowded regions becomes important. This project provides an interactive dashboard that visualizes satellite distribution, analyzes congestion levels, and predicts future risks.

## Features

- 🌍 Interactive Satellite Map
- 📈 Orbital Traffic Analysis Dashboard
- 🚨 Congestion Alerts
- 🤖 AI-Based Risk Prediction
- 🚀 Launch Recommendation Engine
- 📊 Region-Wise Risk Classification

## Tech Stack

- Python
- Streamlit
- Pandas
- Plotly
- Folium
- Scikit-Learn

## How It Works

1. Satellite data is loaded into the system.
2. Satellites are grouped into orbital regions.
3. Traffic density is analyzed for each region.
4. Risk levels are calculated based on congestion.
5. Results are displayed through charts and maps.
6. AI predictions estimate future congestion trends.

## Dashboard Features

### 🌍 Interactive Satellite Map
Visualizes satellites on a world map and highlights different risk levels.

### 📈 Orbital Traffic Distribution
Displays the number of satellites present in different orbital regions.

### 🚨 AI Congestion Alerts
Identifies highly congested orbital regions and generates alerts.

### 🤖 AI Risk Prediction
Predicts future congestion growth and potential risk increases.

### 🚀 Launch Recommendation Engine
Suggests safer orbital regions for future satellite launches.

## Project Goals

The goal of this project is to build a simple decision-support system that helps visualize satellite traffic and understand orbital congestion patterns.
